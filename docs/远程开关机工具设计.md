# 远程开关机工具设计

## 1. 概述

远程开关机工具运行在服务器上，通过 ESP32 风扇控制器实现对远程电脑的开机、重启、物理按钮权限管理及开机状态监测。分为后端（Express）和前端（Vue 3）两个包，通过 Docker 部署。

## 2. 包信息

| 包名 | 路径 | 类型 |
|------|------|------|
| `@power-fan/power-server` | `packages/power-server` | Express 后端 |
| `@power-fan/power-web` | `packages/power-web` | Vue 3 前端 |

## 3. 后端设计 (`power-server`)

### 3.1 目录结构

```
packages/power-server/
├── package.json
├── tsconfig.json
├── Dockerfile
└── src/
    ├── index.ts              # 入口
    ├── config.ts             # 环境变量读取
    ├── routes/
    │   └── power.ts          # 开关机 API
    ├── services/
    │   └── power-monitor.ts  # 开机状态轮询服务
    └── ws/
        └── handler.ts        # WebSocket 处理
```

### 3.2 环境变量

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `ESP32_HOST` | 风扇控制器 IP | 必填 |
| `ESP32_PORT` | TCP 端口 | `8888` |
| `PORT` | Express 端口 | `3002` |

### 3.3 开机状态监测

- **后端轮询**：每 5 秒通过 TCP 客户端调用 `getPowerState()` 查询 ESP32
- **WebSocket 推送**：状态变化时立即推送给所有连接的前端客户端
- 轮询在 TCP 客户端连接成功后启动，断开时暂停

```typescript
interface PowerStatusMessage {
  type: 'power_status';
  data: {
    powerState: 'on' | 'off';
    esp32Connected: boolean;
    timestamp: number;
  };
}
```

### 3.4 REST API

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/status` | 获取当前状态（开机状态 + ESP32 连接状态） |
| `POST` | `/api/power/on` | 远程开机 |
| `POST` | `/api/power/reboot` | 远程重启 |
| `GET` | `/api/buttons` | 获取物理按钮权限状态 |
| `PUT` | `/api/buttons` | 设置物理按钮权限（启用/禁用开机按钮、重启按钮） |

#### 请求/响应示例

```typescript
// PUT /api/buttons
// Request
{ "powerBtn": true, "resetBtn": false }

// Response
{ "ok": true }

// GET /api/status
// Response
{
  "powerState": "on",
  "esp32Connected": true,
  "buttons": { "powerBtn": true, "resetBtn": false }
}
```

### 3.5 WebSocket

- 路径：`ws://host:3002/ws`
- 客户端连接时立即推送当前状态
- 状态变化时推送更新
- ESP32 连接/断开时推送连接状态变化

### 3.6 前端静态文件

- 前端构建产物复制到 `power-server` 的 `public/` 目录
- 通过 `express.static` 提供服务

## 4. 前端设计 (`power-web`)

### 4.1 目录结构

```
packages/power-web/
├── package.json
├── tsconfig.json
├── vite.config.ts
├── index.html
└── src/
    ├── main.ts
    ├── App.vue
    ├── components/
    │   ├── PowerStatus.vue       # 开机状态指示
    │   ├── PowerActions.vue      # 开机/重启按钮
    │   └── ButtonPermission.vue  # 物理按钮权限管理
    └── composables/
        ├── useWebSocket.ts
        └── useApi.ts
```

### 4.2 页面布局

```
┌─────────────────────────────────────────────┐
│              远程开关机控制                   │
├─────────────────────────────────────────────┤
│  开机状态                                    │
│  ┌──────────────────┐                       │
│  │    ● 开机中       │   ESP32: ● 已连接     │
│  │   (绿色指示灯)    │                       │
│  └──────────────────┘                       │
├─────────────────────────────────────────────┤
│  操作                                       │
│  [  开  机  ]    [  重  启  ]               │
│  (操作需二次确认弹窗)                         │
├─────────────────────────────────────────────┤
│  物理按钮权限                                │
│  开机按钮:  [启用/禁用]                      │
│  重启按钮:  [启用/禁用]                      │
└─────────────────────────────────────────────┘
```

### 4.3 组件说明

- **PowerStatus**：通过 WebSocket 实时显示开机状态（绿色=开机，红色=关机），ESP32 连接状态
- **PowerActions**：开机和重启按钮，点击后弹出 Naive UI 确认对话框，确认后调用 API
- **ButtonPermission**：两个开关组件，控制物理按钮启用/禁用

### 4.4 构建产物集成

- `vite.config.ts` 中配置 `build.outDir` 指向 `../power-server/public`
- 开发模式下通过 Vite proxy 代理 API 和 WebSocket 到后端
