# 项目架构

## 1. 概述

本项目是 ESP32 风扇控制/远程开机一体化模块的上位机软件，使用 TypeScript 开发，通过 pnpm monorepo 管理多个包。

- **包管理器**：pnpm v10
- **Node.js 版本**：24+
- **构建工具**：tsc（后端/库）+ Vite（前端）
- **前端技术栈**：Vue 3 (Composition API) + Naive UI + Vite
- **后端框架**：Express
- **实时通信**：WebSocket（ws 库）
- **不配置代码风格工具**（ESLint/Prettier）


## 3. 包说明

| 包名 | 类型 | 说明 |
|------|------|------|
| `@power-fan/tcp-client` | 库 | TCP 客户端，封装通信协议，支持自动重连 |
| `@power-fan/fan-control-server` | 后端 | 风扇控制工具 Express 后端 |
| `@power-fan/fan-control-web` | 前端 | 风扇控制工具 Vue 前端 |
| `@power-fan/power-server` | 后端 | 远程开关机工具 Express 后端 |
| `@power-fan/power-web` | 前端 | 远程开关机工具 Vue 前端 |
| `@power-fan/wifi-config` | CLI | WiFi 配置工具，基于 inquirer.js |

## 4. 包依赖关系

```
@power-fan/tcp-client (核心库)
    ├── @power-fan/fan-control-server (依赖)
    ├── @power-fan/power-server (依赖)
    └── @power-fan/wifi-config (依赖)

@power-fan/fan-control-web → 构建产物嵌入 fan-control-server
@power-fan/power-web → 构建产物嵌入 power-server
```

- `fan-control-web` 和 `power-web` 构建后的静态文件由对应的 server 包通过 `express.static` 提供
- 三个工具包（fan-control-server、power-server、wifi-config）均依赖 `tcp-client` 与 ESP32 通信

## 5. 共享 TypeScript 配置

根目录提供 `tsconfig.base.json`，各包继承基础配置并按需覆盖：

```jsonc
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "declaration": true,
    "declarationMap": true,
    "sourceMap": true,
    "outDir": "./dist",
    "rootDir": "./src"
  }
}
```

## 6. 环境变量

### 6.1 风扇控制工具 (`fan-control-server`)

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `ESP32_HOST` | 风扇控制器 IP 地址 | 必填 |
| `ESP32_PORT` | 风扇控制器 TCP 端口 | `8888` |
| `PORT` | Express 监听端口 | `3001` |

### 6.2 远程开关机工具 (`power-server`)

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `ESP32_HOST` | 风扇控制器 IP 地址 | 必填 |
| `ESP32_PORT` | 风扇控制器 TCP 端口 | `8888` |
| `PORT` | Express 监听端口 | `3002` |

### 6.3 WiFi 配置工具 (`wifi-config`)

无环境变量，ESP32 IP 地址通过交互式输入。

## 7. 开发命令

根 `package.json` 提供以下脚本：

```jsonc
{
  "scripts": {
    "build": "pnpm -r run build",
    "dev:fan": "pnpm --filter @power-fan/fan-control-server dev",
    "dev:power": "pnpm --filter @power-fan/power-server dev",
    "wifi": "pnpm --filter @power-fan/wifi-config start"
  }
}
```
