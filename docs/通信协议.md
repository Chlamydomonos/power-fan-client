# 通信协议

本文档定义 ESP32 电脑开关机与风扇控制模块的 TCP 二进制通信协议。

## 1. 帧格式

所有 TCP 通信数据均封装在以下帧格式中：

```
偏移   长度   字段       说明
──────────────────────────────────────────────
0      2      Magic      固定值 0xAA 0x55（帧头标识）
2      1      CmdID      命令ID
3      2      Length      Payload 长度（大端序，不含 CRC）
5      N      Payload     载荷数据，长度为 Length
5+N    2      CRC16       CRC-16/CCITT 校验（大端序，覆盖 Magic 到 Payload 末尾）
```

**CRC-16/CCITT 参数**：
- 多项式：0x1021
- 初始值：0xFFFF
- 输入/输出不反转
- 异或输出：0x0000

## 2. 响应格式

每个请求帧都会收到一个响应帧。响应帧使用与请求相同的 CmdID，Payload 第一个字节为状态码：

```
状态码   含义
────────────────
0x00     成功
0x01     未知命令
0x02     参数错误
0x03     设备忙
0x04     操作超时
0x05     WiFi未连接
```

## 3. 命令列表

| CmdID | 命令名称 | 请求 Payload | 响应 Payload |
|-------|---------|-------------|-------------|
| 0x01 | 设置WiFi配置 | 见 3.1 | status(1B) |
| 0x02 | 设置BSSID模式 | enable(1B) | status(1B) |
| 0x03 | 读取开机状态 | (无) | status(1B) + power_state(1B) |
| 0x04 | 开机 | (无) | status(1B) |
| 0x05 | 重启 | (无) | status(1B) |
| 0x06 | 设置物理按钮权限 | power_btn(1B) + reset_btn(1B) | status(1B) |
| 0x07 | 读取温度 | (无) | status(1B) + temp(2B) |
| 0x08 | 读取风扇转速 | fan_id(1B) | status(1B) + count(1B) + [fan_id(1B) + rpm(2B)] × count |
| 0x09 | 设置风扇开关 | fan_id(1B) + state(1B) | status(1B) |
| 0x0A | 设置风扇PWM | fan_id(1B) + duty(1B) | status(1B) |

> **fan_id 约定**：1 = 风扇1，2 = 风扇2，3 = 风扇3，0 = 全部风扇

### 3.1 设置WiFi配置 (0x01)

```
请求 Payload:
偏移   长度   字段        说明
──────────────────────────────────────
0      1      ssid_len    SSID 长度 (0-32)
1      ssid_len  ssid     SSID 字符串
1+L    6      bssid       BSSID (6字节 MAC 地址)
7+L    1      pwd_len    密码长度 (0-64)
8+L    pwd_len  pwd      密码字符串
```

- 设置后立即保存到 NVS，但不会立即重连（需重启或等待重连逻辑触发）
- SSID 和 BSSID 都保存，实际使用哪个取决于 BSSID 模式是否启用
- SSID 和密码在两种模式下均为必填，BSSID 模式通过 `WiFi.begin(ssid, password, 0, bssid)` 的第 4 个参数指定目标 AP 的 MAC 地址
- SSID 长度为 0 时表示清空 WiFi 配置（重置为未配置状态，下次启动将进入 AP 模式）

### 3.2 设置BSSID模式 (0x02)

```
请求 Payload:
偏移   长度   字段      说明
────────────────────────
0      1      enable    0 = 禁用（使用 SSID 模式）
                        1 = 启用（使用 BSSID 模式）
```

- 设置后保存到 NVS
- 启用 BSSID 模式后，WiFi 连接时使用 `WiFi.begin(ssid, password, 0, bssid)` 直接指定目标 AP 的 BSSID

### 3.3 读取开机状态 (0x03)

```
响应 Payload:
偏移   长度   字段          说明
──────────────────────────────
0      1      status        状态码
1      1      power_state   0 = 关机, 1 = 开机
```

- 读取 GPIO 27（主板电源 LED）电平，高电平 = 开机

### 3.4 开机 (0x04)

```
请求 Payload: (无)
响应 Payload:
偏移   长度   字段     说明
──────────────────────────
0      1      status   状态码
```

- GPIO 33 输出高电平 200ms，然后恢复低电平
- 模拟按下主板电源按钮

### 3.5 重启 (0x05)

```
请求 Payload: (无)
响应 Payload:
偏移   长度   字段     说明
──────────────────────────
0      1      status   状态码
```

- GPIO 32 输出高电平 200ms，然后恢复低电平
- 硬重启：直接短接主板 RESET 引脚

### 3.6 设置物理按钮权限 (0x06)

```
请求 Payload:
偏移   长度   字段         说明
──────────────────────────────
0      1      power_btn    0 = 禁用物理开机按钮, 1 = 允许
1      1      reset_btn    0 = 禁用物理重启按钮, 1 = 允许
```

- 设置后保存到 NVS
- 禁用后，按下对应物理按钮不会执行任何操作

### 3.7 读取温度 (0x07)

```
响应 Payload:
偏移   长度   字段     说明
──────────────────────────────
0      1      status   状态码
1      2      temp     温度值（大端序，有符号整数，单位 0.1℃）
```

- 例如 temp = 255 表示 25.5℃
- 例如 temp = -30 表示 -3.0℃

### 3.8 读取风扇转速 (0x08)

```
请求 Payload:
偏移   长度   字段     说明
────────────────────────
0      1      fan_id   1/2/3 = 指定风扇, 0 = 全部风扇
```

```
响应 Payload:
偏移   长度   字段     说明
────────────────────────────────────────
0      1      status   状态码
1      1      count    返回的风扇数量
2      ...     [fan_id(1B) + rpm(2B)] × count
```

- rpm 为大端序无符号整数，单位 RPM
- fan_id=0 时，count=3，依次返回风扇1/2/3的转速
- 风扇关闭时 rpm=0

### 3.9 设置风扇开关 (0x09)

```
请求 Payload:
偏移   长度   字段     说明
────────────────────────────────
0      1      fan_id   1/2/3 = 指定风扇, 0 = 全部风扇
1      1      state    0 = 关, 1 = 开
```

- fan_id=0 时同时设置 3 个风扇的开关
- 关闭风扇时同时将 PWM 占空比设为 0
- 开启风扇时恢复之前设置的 PWM 占空比（默认 255 = 100%）

### 3.10 设置风扇PWM (0x0A)

```
请求 Payload:
偏移   长度   字段     说明
────────────────────────────────
0      1      fan_id   1/2/3 = 指定风扇, 0 = 全部风扇
1      1      duty     PWM 占空比 (0-255, 0=0%, 255=100%)
```

- fan_id=0 时同时设置 3 个风扇的 PWM
- 风扇处于关闭状态时设置 PWM 不会自动开启风扇，但会记录占空比值

## 4. 通信流程示例

### 示例1：读取温度

```
请求: AA 55 07 00 00 [CRC16]
响应: AA 55 07 00 03 00 00 FF [CRC16]
      (status=0x00, temp=0x00FF=255 → 25.5℃)
```

### 示例2：设置风扇1 PWM为50%

```
请求: AA 55 0A 00 02 01 7F [CRC16]
      (fan_id=1, duty=0x7F=127 → ~50%)
响应: AA 55 0A 00 01 00 [CRC16]
      (status=0x00)
```

### 示例3：读取全部风扇转速

```
请求: AA 55 08 00 01 00 [CRC16]
      (fan_id=0, 全部风扇)
响应: AA 55 08 00 08 00 03 01 05 14 02 04 D2 03 03 E8 [CRC16]
      (status=0x00, count=3,
       风扇1 rpm=0x0514=1300,
       风扇2 rpm=0x04D2=1234,
       风扇3 rpm=0x03E8=1000)
```
